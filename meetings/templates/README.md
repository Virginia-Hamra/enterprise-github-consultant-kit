# Meeting Templates

Generic, customer-agnostic meeting structures. Copy when scheduling; do not edit in place.

| Template | Use for |
|---|---|
| `kickoff-meeting.md` | Engagement / phase kickoff |
| `discovery-interview.md` | 1:1 or small-group discovery |
| `working-session.md` | Hands-on co-build / co-design |
| `architecture-review.md` | Design review with customer architects |
| `demo-session.md` | Capability or solution demo |
| `steering-committee.md` | Executive / sponsor cadence |
| `status-update.md` | Weekly / bi-weekly cadence |
| `retrospective.md` | Phase or engagement retro |
| `handoff-meeting.md` | Knowledge transfer & closeout |
