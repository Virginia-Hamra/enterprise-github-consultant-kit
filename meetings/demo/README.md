# Demo Scripts

Reusable, sanitized demo scripts that you can pull from when scoping or running a customer demo. Each script: **audience → narrative arc → setup → step-by-step → talking points → fallback**.

| Script | Audience | Run time |
|---|---|---|
| `ghas-demo-script.md` | Security, AppSec, eng leadership | 30–45 min |
| `copilot-demo-script.md` | Eng leadership, ICs | 30–45 min |
| `actions-cicd-demo-script.md` | Platform / DevOps | 30–60 min |
| `governance-demo-script.md` | Platform, security, GRC | 30 min |
| `migration-demo-script.md` | Migration owner, platform | 30–45 min |

> Treat each script as a baseline. Always tailor scenarios to the customer's stack and concerns surfaced in discovery.
