# Demo Prep

Run ≥ 2 business days before. Bad demos kill credibility.

## Audience
- [ ] Audience roles confirmed
- [ ] Their goals / questions known in advance
- [ ] Demo tailored to their concerns (not generic)

## Script
- [ ] Demo script from `meetings/demo/<file>.md` reviewed
- [ ] Customized scenarios written
- [ ] Backup / fallback plan if live demo fails (recorded video)

## Environment
- [ ] Demo env / sandbox tested ≤ 4h before
- [ ] No flaky steps; rehearsed end-to-end
- [ ] Reset script ready to re-run
- [ ] Browser / shell / IDE pre-staged with bookmarks, terminal cwd, tabs

## Materials
- [ ] Slides (intro + summary) ready
- [ ] Reference docs to send after
- [ ] Note doc from `templates/demo-session.md`
