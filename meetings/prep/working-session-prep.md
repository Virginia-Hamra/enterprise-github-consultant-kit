# Working Session Prep

Run ≥ 2 business days before. Working sessions fail without prep.

## Define the session
- [ ] Single-sentence objective
- [ ] Definition of Done — explicit, testable
- [ ] Time box decided
- [ ] Driver / co-driver / observer roles assigned

## Pre-requisites verified (the day before)
- [ ] Access tested end-to-end (every tool/account)
- [ ] Test environment / sandbox repo ready
- [ ] Approvals in place (if production touch)
- [ ] Rollback plan documented
- [ ] Required customer attendees confirmed

## Materials
- [ ] Playbook from `meetings/working-session/<file>.md` reviewed
- [ ] Step-by-step script written
- [ ] Note doc from `templates/working-session.md`

## Risk check
- [ ] Identified what could go wrong & how to recover
- [ ] Confirmed change-control sign-off (if needed)
