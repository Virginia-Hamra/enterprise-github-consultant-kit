# Handoff Prep

Run ≥ 1 week before handoff.

## Documentation complete
- [ ] Architecture diagrams final
- [ ] Operations runbooks for top tasks
- [ ] Incident response runbook
- [ ] Audit / evidence collection guide
- [ ] Monitoring / alerting guide
- [ ] Cost / licensing levers documented
- [ ] Open items list (with owners)

## Knowledge transfer
- [ ] Walkthrough sessions scheduled (architecture, ops, IR, audit)
- [ ] Recordings planned

## Customer readiness
- [ ] Receiving team identified & invited
- [ ] Top-10 ops tasks dry-run with customer team
- [ ] Support model / escalation path agreed in writing

## Closeout
- [ ] Sign-off doc prepared
- [ ] Access revocation plan ready
- [ ] Engagement folder archive plan
- [ ] Retrospective scheduled (internal)
