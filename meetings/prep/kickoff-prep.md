# Kickoff Prep

Run ≥ 3 business days before kickoff.

## Materials
- [ ] Engagement charter draft
- [ ] Scope summary (in / out)
- [ ] Proposed RACI
- [ ] Communication plan proposal
- [ ] Discovery schedule proposal
- [ ] Risk register seeded
- [ ] Pre-read sent to attendees

## Logistics
- [ ] Calendar invite with agenda
- [ ] Recording / note-taking permission confirmed
- [ ] Customer collab tool access confirmed
- [ ] Note doc created from `templates/kickoff-meeting.md`

## Internal alignment
- [ ] Delivery team dry-run on agenda
- [ ] Roles for the meeting assigned (lead, scribe, demo)
- [ ] Open questions for the customer compiled
