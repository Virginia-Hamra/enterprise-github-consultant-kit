# Copilot Rollout Checklist

Owner: DevEx lead. Use for staged Copilot Business / Enterprise rollout.

## Approvals
- [ ] Legal / IP review complete
- [ ] Security review complete
- [ ] Privacy / DPIA complete (if applicable)
- [ ] Executive sponsor signoff

## Configuration
- [ ] Policy: public code matching set
- [ ] Content exclusions configured (paths / repos / file types)
- [ ] Audit log streaming captures Copilot events
- [ ] Feature toggles set: Chat, code review, coding agent, Extensions, knowledge bases

## Pilot
- [ ] Pilot cohort selected (cross-functional, 20–50 users)
- [ ] Baseline metrics captured (cycle time, satisfaction)
- [ ] Training delivered
- [ ] Feedback channel established
- [ ] Office hours scheduled

## Broader rollout
- [ ] Enablement collateral published (quick-start, prompt patterns)
- [ ] Champion network identified
- [ ] Support escalation defined
- [ ] Metrics dashboard live

## Governance
- [ ] Acceptable use policy published
- [ ] AI-generated code review guidance
- [ ] Quarterly policy / metrics review scheduled
