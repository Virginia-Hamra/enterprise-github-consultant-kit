# Discovery Questionnaires

Structured intake forms by domain. Send to the customer ahead of discovery interviews to accelerate fact-finding.

| File | Audience | Purpose |
|---|---|---|
| `current-state-platform.md` | Platform leads | Inventory current GitHub footprint (orgs, repos, plans) |
| `identity-and-access.md` | IAM / Security | IdP, SSO, SCIM, PAT/SSH, emergency access |
| `security-and-compliance.md` | Security / GRC | GHAS usage, secret scanning, compliance frameworks in scope |
| `cicd-and-actions.md` | DevOps / Platform | Existing CI tools, Actions usage, runners, OIDC |
| `developer-experience.md` | Eng leadership | Workflows, friction points, golden paths, metrics |
| `migration-readiness.md` | Migration owner | Source platform inventory, scale, timelines |
| `copilot-readiness.md` | Eng / Legal / Sec | Copilot eligibility, content exclusions, policies |

Each questionnaire follows the same shape: **context → questions (grouped) → artifacts requested → follow-up actions**.
