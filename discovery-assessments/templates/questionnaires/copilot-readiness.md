# GitHub Copilot Readiness Questionnaire

> **Audience:** Eng / Legal / Security &nbsp; | &nbsp; **Time:** ~45 min

## Eligibility & licensing
1. Copilot SKU intent (Business / Enterprise)?
2. Seat estimate, rollout phasing?
3. Budget owner?

## Policy & legal
1. Approval status from Legal / IP / Privacy?
2. Public code matching policy preference (block / allow)?
3. Data residency / telemetry concerns?
4. Required content exclusions (paths, repos, file types)?

## Security
1. Sensitive repo identification process?
2. Secret scanning coverage prior to Copilot enablement?
3. Logging / audit requirements for Copilot usage?

## Enablement
1. Pilot cohort identified?
2. Training plan?
3. Success metrics (acceptance rate, satisfaction, cycle time)?
4. Champion network?

- [ ] Copilot Chat
- [ ] Copilot in PRs (code review)
- [ ] Copilot coding agent
- [ ] Copilot Extensions / MCP
- [ ] Knowledge bases / Spaces
- [ ] Custom instructions / prompt files
