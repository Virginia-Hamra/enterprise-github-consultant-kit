# Scorecards

Quantitative posture rubrics used during assessment. Each scorecard scores domains 0–4 (Initial → Optimizing) and produces a heatmap for the assessment report.

| Scorecard | Domain |
|---|---|
| `maturity-model-scorecard.md` | Overall GitHub Enterprise maturity |
| `security-posture-scorecard.md` | Security & compliance posture |
| `devex-scorecard.md` | Developer experience |
| `platform-ops-scorecard.md` | Platform operations |
| `ai-readiness-scorecard.md` | Copilot / AI tooling readiness |

Levels:
- **0 — Absent**: capability does not exist
- **1 — Initial**: ad-hoc, undocumented
- **2 — Repeatable**: documented, inconsistently applied
- **3 — Defined**: standardized, broadly applied
- **4 — Optimizing**: measured, automated, continuously improved
