# Interview Guides

Audience-specific scripts for discovery interviews. Pair with the relevant questionnaire under `../questionnaires/`.

| Guide | Audience | Length |
|---|---|---|
| `executive-stakeholder.md` | Sponsor, VP/Director | 30 min |
| `platform-team.md` | GitHub admins, platform eng | 60 min |
| `security-team.md` | CISO org, AppSec, GRC | 60 min |
| `developer-team.md` | IC engineers, tech leads | 45 min |
| `migration-owner.md` | Migration program lead | 60 min |

Each guide: **objectives → opening → core questions → probing prompts → close & next steps.**
