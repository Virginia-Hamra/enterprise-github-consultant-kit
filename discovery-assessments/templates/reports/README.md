# Report Templates

Customer-facing deliverable templates. Copy into `engagements/<customer>/03-recommendations/` (or `02-assessment/`) and fill in.

| Template | Output |
|---|---|
| `current-state-assessment-template.md` | Snapshot of "what is" with scorecard heatmap |
| `gap-analysis-template.md` | Current vs. target, prioritized gaps |
| `risk-register-template.md` | Risks, likelihood/impact, mitigation, owner |
| `recommendations-roadmap-template.md` | Phased recommendations with sequencing |
| `architecture-decision-record-template.md` | ADR for significant decisions |
| `executive-summary-template.md` | One-pager for leadership |
