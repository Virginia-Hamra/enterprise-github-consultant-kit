# Templates

Reusable, customer-agnostic assets. Copy into an engagement folder and customize — never edit in place during delivery.

- `questionnaires/` — Structured intake by domain
- `checklists/` — Phase-gated checklists
- `interview-guides/` — Audience-specific scripts
- `scorecards/` — Maturity & posture rubrics
- `reports/` — Deliverable templates
